# 截图素材清单（Screenshots）

README 与 README.zh-CN.md 引用了 `docs/screenshots/` 下的图片。请按以下清单提供截图，命名与 README 中的引用保持一致：

| 文件名 | 内容 | 建议 |
| --- | --- | --- |
| `light.png` | 浅色模式主窗口 | 1280×800 左右，含多标签与状态栏 |
| `dark.png` | 深色模式主窗口 | 同上，深色主题 |
| `find-bar.png` | 查找栏展开（含匹配高亮） | 可选 |
| `tabs.png` | 多标签拖拽/右键菜单 | 可选 |

> 占位引用（`docs/screenshots/light.png` / `dark.png`）在图片放入前会显示为断裂图；README 顶部已留 TODO 注释。
> 截图后建议同时提供一张 1280×800 的浅色主窗口作为仓库 Social Preview（仓库设置 → Social preview）。
