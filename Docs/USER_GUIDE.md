# Notepad for macOS 用户手册

> 版本：v1.0.0 ｜ 适用：macOS 12.0 及以上（Apple Silicon / Intel）

## 1. 安装

### 方式一：下载 DMG

从 GitHub Releases 下载 `Notepad-*.dmg`，双击打开后把 `Notepad.app` 拖入「应用程序」文件夹。

> 当前构建未签名：首次打开请在 Dock 或「应用程序」中**右键** `Notepad.app` → **打开**，并点击「打开」确认；或终端执行 `xattr -dr com.apple.quarantine Notepad.app`。

### 方式二：从源码构建

需要 Xcode 15+ 与 XcodeGen：

```bash
./Scripts/setup.sh && make build
# 产物：DerivedData/.../Notepad.app；无 Xcode 可用 ./Scripts/dev-build.sh
```

## 2. 快速上手

- **新建标签页** `⌘N`，**新建窗口** `⇧⌘N`，**打开** `⌘O`，**保存** `⌘S`，**另存为** `⇧⌘S`。
- 打开文件时自动检测**编码**与**换行符**，状态栏右侧显示；点击即可切换并保存。
- 关闭标签页 `⌘W`；关闭窗口 `⇧⌘W`。
- 应用**关闭后自动保存**（默认开启）：编辑内容 ≤1s 节流写入会话备份，崩溃或退出后再次启动自动恢复全部标签与光标位置。自动保存开关（偏好设置项）将在后续版本提供界面，当前默认开启。

## 3. 常用操作

| 操作 | 方式 |
| --- | --- |
| 查找 / 替换 | `⌘F` / `⌥⌘F`，`⌘G` 下一个，`⇧⌘G` 上一个 |
| 转到行 | `⌃G` |
| 插入日期时间 | `F5` |
| 缩放 | `⌘+` / `⌘-` / `⌘0`（10%–500%） |
| 自动换行 | `⌥⌘W`（格式菜单可勾选） |
| 字体 | 格式 → 字体…（系统字体面板） |
| 状态栏 | `⌘/` 显示/隐藏 |
| 主题 | 视图 → 主题：浅色 / 深色 / 跟随系统 |
| 标签切换 | `⇧⌘]` / `⇧⌘[` 或点击标签 |
| 打印 / 页面设置 | `⌘P` / 文件 → 页面设置… |

## 4. 编码与换行符

- 支持编码：UTF-8、UTF-16 LE/BE、UTF-32 LE/BE（带/不带 BOM）、GB18030（GBK/GB2312）、Big5、Windows-1252。
- 打开时自动检测；状态栏点击编码名称，在菜单中选择后**重新打开**生效；保存保持当前编码与原换行符格式。
- 换行符：LF / CRLF / CR 自动识别，状态栏一键转换。

## 5. 大文件

超过 10MB 的文件会提示「将以只读模式打开」，确认后整体加载为只读，编辑与保存被禁用（避免卡死）。

## 6. 自动保存与会话恢复

- 会话备份始终生效（与自动保存开关无关），位置：`~/Library/Application Support/Notepad/Backups/`。
- 自动保存开关只控制「是否自动写回原文件」：
  - 开：已存盘文件编辑后自动保存；
  - 关：关闭标签/窗口时按 macOS 惯例提示保存。
- 正常关闭的标签会删除对应备份；退出应用时备份保留（用于下次启动恢复）。

## 7. 打印

文件 → 打印…：页眉居中显示文件名，页脚显示「第 X 页 共 Y 页」，使用文档当前字体，黑字白底。页面设置可调整纸张、方向与页边距。

## 8. 快捷指令与 Touch Bar

- macOS 13+：快捷指令 App 提供「用 Notepad 打开文件」「创建新文本文件」两个动作。
- Touch Bar（支持的机型）：默认新建/打开/保存/查找/自动换行，编辑时提供剪切/复制/粘贴/撤销/重做。

## 9. 服务菜单（macOS）

在任意应用中选中文字 → 服务 → 「用所选文字新建文档」，即可在 Notepad 中打开新文档并带入所选文字。

## 10. 常见问题

**Q：打开某些中文文件显示乱码？**
打开后点击状态栏编码，选择正确的编码（如 GB18030）后重新打开；保存时保持该编码。

**Q：从 Windows 复制的 .txt 保存后再回 Windows 打开不一致？**
确认换行符为 CRLF（状态栏切换）与编码为 GB18030/UTF-8 后保存即可。

**Q：如何反馈问题？**
帮助 → 发送反馈…（邮件），或到 GitHub Issues 提交（附 macOS 版本与复现步骤）。

## 11. 隐私

应用不上传任何文件内容；会话备份仅存本机；崩溃日志可选上报且已匿名化（不含文件路径与内容片段）。详见仓库根目录 `06_RELEASE.md` 第 6 节。
