# Notepad for macOS — UI 设计规范 (UI_DESIGN)

> **版本**：v1.1  
> **目标**：像素级复刻 Windows 11 Notepad 视觉与交互，同时融入 macOS 原生规范  
> **v1.1 修订**：标签栏选型对齐自绘 NPTabBarView；修正不存在的 API 与字号表述；选中高亮改为硬编码 `#0078D4`（NPColorPalette）；响应式分档与最小宽度对齐 400pt；状态栏编码清单补齐 UTF-32 LE/BE 与 Big5；标签右键菜单对齐 PRD FR-002 五项；补充标签拖拽视觉规范与深色未保存指示点色值；新增大文档动画降级、本地化 VoiceOver 朗读串等约定  
> **设计工具参考**：Figma / Sketch 组件库规范

---

## 1. 设计原则

1. **像素级复刻**：Windows 11 Notepad 的每一个像素、间距、颜色值都需精确映射
2. **macOS 原生融合**：菜单栏、窗口控件、字体渲染、动画曲线使用 macOS 标准
3. **无侵入感**：用户应感觉"这就是 macOS 上的 Notepad"，而非"一个仿 Win 的 App"
4. **响应式**：从 13 寸 MacBook 到 32 寸 4K 显示器，界面均保持清晰可用

### 2.3 语义化颜色（macOS 适配）

以下语义颜色**仅用于非复刻区域**（如辅助控件、系统对话框）；复刻区域一律以 2.1/2.2 硬编码色值为验收基准，统一封装进 `NPColorPalette`：

```swift
// 编辑区背景（非复刻场景 fallback）
editorBackground: NSColor.textBackgroundColor  // 自动跟随系统

// 编辑区文字
editorText: NSColor.textColor

// 状态栏
statusBarBackground: NSColor.controlBackgroundColor
```

> **注意**：选中高亮**不使用**语义颜色——`NSColor.selectedTextBackgroundColor` 系统默认为灰色，不可用于复刻；选中高亮一律使用硬编码 `#0078D4`（Win11 蓝），封装进 `NPColorPalette`。其余语义颜色在 macOS 12 下可能与上述硬编码值略有差异，仅用于非复刻区域；最终视觉验收以硬编码值为准，语义颜色仅作为 fallback。

## 3. 字体与排版

### 3.1 编辑区字体

| 属性     | 值                           | 说明                 |
| -------- | ---------------------------- | -------------------- |
| 默认字体 | `SF Mono`                    | macOS 原生等宽字体   |
| 备选字体 | `Menlo`, `Monaco`, `Courier` | 降级链               |
| 默认字号 | 12pt                         | 默认 SF Mono 12pt（PRD FR-014），属 macOS 化调整，非 Win11 原值（Win11 默认为 Consolas 11pt） |
| 行高     | 1.2 × 字号                   | 约 14.4pt            |
| 字间距   | 0                            | 等宽字体无需额外调整 |
| 字体平滑 | 开启                         | 使用系统默认文本抗锯齿（`NSGraphicsContext.shouldAntialias`，一般无需干预） |
| 连字     | 关闭                         | 纯文本编辑器不需要   |

### 3.2 界面字体

> 下表 `SF Pro Text` 为设计稿标注；实现统一使用 `NSFont.systemFont(ofSize:weight:)` 按名加载。

| 区域   | 字体          | 字号 | 字重    |
| ------ | ------------- | ---- | ------- |
| 菜单栏 | `SF Pro Text` | 13pt | Regular |
| 状态栏 | `SF Pro Text` | 11pt | Regular |
| 标签页 | `SF Pro Text` | 12pt | Medium  |
| 查找栏 | `SF Pro Text` | 12pt | Regular |
| 对话框 | `SF Pro Text` | 13pt | Regular |

### 3.3 状态栏信息格式

```
Ln {行号}, Col {列号}      {缩放}%      {换行符格式}      {编码}
```

- 行号、列号：从 1 开始计数（与 Win11 一致）
- 缩放：整数百分比，无小数
- 换行符格式显示：
  - `Windows (CRLF)`
  - `Unix (LF)`
  - `Macintosh (CR)`（Win11 原版文案；以 04_MODULE_API.md 的 `NPLineEnding.displayName` 为唯一实现依据）
- 编码显示：
  - `UTF-8`
  - `UTF-8 BOM`
  - `UTF-16 LE`
  - `UTF-16 BE`
  - `UTF-32 LE`
  - `UTF-32 BE`
  - `ANSI`（Win11 即显示 ANSI；其实现为 Windows-1252）
  - `GB18030`
  - `Big5`

## 5. 组件详细规范

### 5.1 标签页（Tab）

> **v1.2 修订（用户决策）**：标签视觉从 Win11 复刻改为 **macOS 原生风格**（Safari/Finder 方向）。
> 自绘架构与交互不变（`NPTabBarView`/`NPTabItemView`、拖拽排序、拖出成新窗口、右键菜单），
> 仅视觉规格替换；配色以系统语义色为准（深浅色自适应），不再使用硬编码 Win11 色值。

```
┌──────────────────────────────────────────────────────┐
│  ╭──────────────╮ ╭──────────────╮ ╭──────────────╮  │
│  │ ● 文件名.txt │ │ × 文件名2    │ │   文件名3    │  │
│  ╰──────────────╯ ╰──────────────╯ ╰──────────────╯  │
└──────────────────────────────────────────────────────┘
```

- **形态**：标签为浮于标签栏背景上的**胶囊卡片**（左右两头半圆形，圆角=卡片高度一半）
- **尺寸**：栏高 26pt；卡片高 24pt（垂直内缩 1pt，上下各留 1pt 间隙）；卡片间距 2pt；左端内缩 4pt
- **宽度**：自适应，最小 120pt，最大 240pt（不变）
- **选中态**：明亮卡片色 `NSColor.controlBackgroundColor`，文字 `NSColor.labelColor`
- **未选中**：背景透明，文字 `NSColor.secondaryLabelColor`；悬停微显（label 色 6% 透明底色）
- **分隔线**：相邻两个标签都未选中时，之间绘制 1px 竖线（`NSColor.separatorColor`，卡片高度内缩 3pt）；选中卡片两侧不画
- **关闭按钮**：**左侧**（macOS 惯例），14×14pt，悬停或选中时显示；未选中时 `tertiaryLabelColor`，选中时 `secondaryLabelColor`
- **未保存标记**：圆点 ● 6pt，**系统强调色**（`NSColor.controlAccentColor`）；与关闭按钮共槽位——平时显示圆点，悬停/选中时让位给关闭按钮（Safari 式互换）
- **字体**：系统字体 12pt
- **右键菜单**（对齐 PRD FR-002，共 5 项，不变）：
  - 关闭
  - 关闭其他标签页
  - 关闭右侧标签页
  - 复制标签页
  - 在 Finder 中显示
- **拖拽交互**（对应 04_MODULE_API.md 的 `didMoveTabFrom` / `didDragOutTabAt`，逻辑不变）：
  - **插入指示线**：拖拽排序时，在目标插入位置绘制 2pt 宽竖直指示线，色值为**系统强调色**（`NSColor.controlAccentColor`），高度为标签栏高度减 8pt，垂直居中
  - **拖拽占位**：被拖标签降低不透明度至 30% 作为原位占位（浮层缩略图为后续增强项）
  - **拖出窗口**：标签被拖出标签栏区域超过 20pt 时判定拖出，松开后以该标签形成新窗口；拖回标签栏则恢复排序指示

### 5.2 查找栏（Find Bar）

```
┌─────────────────────────────────────────────────────────┐
│  🔍 [搜索内容...                    ] [∧] [∨] [选项▼]  │
│  找到 3/12                                             │
└─────────────────────────────────────────────────────────┘
```

- **位置**：编辑区上方，显示时推动编辑区下移，不遮挡内容（v1.2 修订：原为覆盖内容不推动布局，悬浮遮挡会导致光标/命中区域重叠问题）
- **背景**：纯色 `NPColorPalette.findBarBackground`（浅 #F0F0F0 / 深 #2B2B2B）（v1.3 修订：原 `NSVisualEffectView` 毛玻璃浅色下与编辑区背景难区分）
- **高度**：44pt（单行）/ 76pt（展开替换）
- **输入框**：圆角 6pt，高度 24pt
- **按钮**：无边框图标按钮，24×24pt
- **匹配高亮**：编辑区内所有匹配项黄色背景 `#FFFF00`（浅色）/ `#7D6608`（深色），当前匹配项橙色边框 `#FF8C00`
- **动画**：从顶部滑入/滑出，duration 0.2s，ease-out

### 5.3 替换栏（Replace Bar）

```
┌─────────────────────────────────────────────────────────┐
│  🔍 [查找...                       ] [∧] [∨] [选项▼]  │
│  📝 [替换为...                     ] [替换] [全部替换]  │
└─────────────────────────────────────────────────────────┘
```

- **展开方式**：在查找栏下方展开，高度增加 32pt
- **替换按钮**：圆角矩形按钮，高度 22pt，内边距 12pt 水平
- **全部替换按钮**：主按钮样式（蓝色背景 `#0078D4`，白色文字）

### 5.4 状态栏（Status Bar）

```
┌─────────────────────────────────────────────────────────┐
│  Ln 12, Col 34        100%        Windows (CRLF)  UTF-8 │
└─────────────────────────────────────────────────────────┘
```

- **高度**：22pt
- **背景**：`#F3F3F3`（浅色）/ `#2D2D2D`（深色）
- **顶部边框**：1pt `#E5E5E5`（浅色）/ `#3C3C3C`（深色）
- **文字对齐**：左对齐（Ln/Col），右对齐（编码）
- **可点击区域**：每个信息块均为可点击按钮，hover 时背景略深
- **点击反馈**：弹出对应功能的菜单/对话框

### 5.5 转到行对话框（Go To Line）

```
┌─────────────────────────┐
│  转到行                  │
│  ─────────────────────  │
│  行号: [________]        │
│                         │
│       [取消] [转到]      │
└─────────────────────────┘
```

- **窗口样式**：NSPanel，非模态浮动面板，随宿主窗口联动关闭（"浮动"仅指面板层级行为，与 FR-017"始终在最前"全局开关无关）
- **尺寸**：280pt × 120pt
- **输入框**：仅允许数字，自动选中当前行号
- **快捷键**：`⌃G` 打开，Enter 确认，Esc 取消

## 6. 动画与过渡

### 6.1 窗口动画

| 场景     | 动画                       | 时长     | 曲线     |
| -------- | -------------------------- | -------- | -------- |
| 新建窗口 | 使用系统默认窗口出现行为     | 系统控制 | —        |
| 关闭窗口 | 透明度渐变 + 缩放          | 0.2s     | ease-in  |
| 最小化   | macOS 标准 Genie/Dock 动画 | 系统控制 | —        |

### 6.2 界面元素动画

| 场景            | 动画                                | 时长  |
| --------------- | ----------------------------------- | ----- |
| 查找栏出现      | 从顶部 translateY(-100%) → 0        | 0.2s  |
| 查找栏消失      | translateY(0) → -100%，透明度 1 → 0 | 0.15s |
| 标签页切换      | 内容区淡入淡出                      | 0.1s  |
| 状态栏显示/隐藏 | 高度 0 → 22pt / 22pt → 0            | 0.2s  |
| 主题切换        | 颜色渐变过渡                        | 0.3s  |

> **性能降级**：大文档（>1MB）下，主题切换等动画降级为瞬时切换，保证打字延迟 <16ms 的性能预算。

### 6.3 交互反馈

| 场景               | 反馈                                   |
| ------------------ | -------------------------------------- |
| 点击状态栏         | 背景色瞬间变深 10%，松开后恢复         |
| 悬停标签页关闭按钮 | 按钮背景出现圆形灰色底 `#E5E5E5`       |
| 保存成功           | 状态栏短暂显示"已保存"，2s 后恢复      |
| 编码检测失败       | 状态栏编码区域文字变红，点击弹出选择框 |

## 9. 无障碍（Accessibility）规范

### 9.1 VoiceOver 支持

所有朗读串统一走 `NSLocalizedString`，使用稳定英文 key（不随文案变化而变）；第一阶段提供简体中文 / 繁体中文 / 英文三种语言。

| 元素   | 英文 key                     | 英文                                    | 简体中文                                | 繁体中文                                |
| ------ | ---------------------------- | --------------------------------------- | --------------------------------------- | --------------------------------------- |
| 编辑区 | `a11y.editor`                | "Text editing area, {encoding}, {n} lines" | "文本编辑区，{文件编码}，{行数} 行"     | "文字編輯區，{檔案編碼}，{行數} 行"     |
| 标签页 | `a11y.tab`                   | "{filename} tab, {unsaved/saved}"       | "{文件名} 标签页，{未保存/已保存}"      | "{檔案名稱} 標籤頁，{未儲存/已儲存}"    |
| 状态栏 | `a11y.statusBar`             | "Status bar, line {n}, column {n}, zoom {n}%..." | "状态栏，行 {n}，列 {n}，缩放 {n}%..." | "狀態列，行 {n}，欄 {n}，縮放 {n}%..." |
| 查找栏 | `a11y.findBar`               | "Find, text field"                      | "查找，编辑文本"                        | "尋找，編輯文字"                        |

- [ ] 关键色值/间距/字号逐项与本规范第 2、3、4 节表格比对一致
