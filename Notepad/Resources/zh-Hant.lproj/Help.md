# Notepad 輔助說明

## 快速上手

- **新增標籤頁** `⌘N`，**新增視窗** `⇧⌘N`，**打開** `⌘O`，**儲存** `⌘S`，**另存新檔** `⇧⌘S`。
- 打開檔案時自動偵測**編碼**與**換行符號**，顯示在狀態列右側；點按即可切換。
- **關閉標籤頁** `⌘W`；**關閉視窗** `⇧⌘W`。
- **自動儲存**預設開啟：結束或當機後再次啟動，自動回復全部標籤與游標位置。

## 常用操作

- **尋找 / 取代**：`⌘F` / `⌥⌘F`；`⌘G` 下一個，`⇧⌘G` 上一個。
- **跳至行**：`⌃G`。
- **插入日期時間**：`F5`。
- **縮放**：`⌘+` / `⌘-` / `⌘0`（10%–500%）。
- **自動換行**：`⌥⌘W`（格式選單可勾選）。
- **字體**：格式 → 字體…（系統字體面板）。
- **狀態列**：`⌘/` 顯示或隱藏。
- **主題**：顯示方式 → 主題（淺色 / 深色 / 跟隨系統）。
- **標籤切換**：`⇧⌘]` / `⇧⌘[`。
- **列印 / 頁面設定**：`⌘P` / 檔案 → 頁面設定…。

## 編碼與換行符號

- 支援 UTF-8、UTF-16 LE/BE、UTF-32 LE/BE（含 / 不含 BOM）、GB18030（GBK / GB2312）、Big5、Windows-1252。
- 打開時自動偵測；點按狀態列編碼名稱選擇其他編碼後**重新打開**生效，儲存時保持目前編碼與原換行符號格式。
- 換行符號 LF / CRLF / CR 自動識別，狀態列一鍵轉換。

## 大型檔案

超過 10MB 的檔案將以**唯讀模式**打開，編輯與儲存會被停用，避免卡死。

## 列印

檔案 → 列印…：頁首置中顯示檔名，頁尾顯示「第 X 頁 共 Y 頁」；頁面設定可調整紙張、方向與頁邊距。

## 常見問題

**打開某些中文檔案顯示亂碼？**

點按狀態列編碼，選擇正確的編碼（如 GB18030）後重新打開；儲存時保持該編碼。

**如何回報問題？**

輔助說明 → 傳送意見回饋…（郵件），請附上 macOS 版本與重現步驟。
