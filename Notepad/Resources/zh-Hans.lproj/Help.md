# Notepad 帮助

## 快速上手

- **新建标签页** `⌘N`，**新建窗口** `⇧⌘N`，**打开** `⌘O`，**保存** `⌘S`，**另存为** `⇧⌘S`。
- 打开文件时自动检测**编码**与**换行符**，显示在状态栏右侧；点击即可切换。
- **关闭标签页** `⌘W`；**关闭窗口** `⇧⌘W`。
- **自动保存**默认开启：退出或崩溃后再次启动，自动恢复全部标签与光标位置。

## 常用操作

- **查找 / 替换**：`⌘F` / `⌥⌘F`；`⌘G` 下一个，`⇧⌘G` 上一个。
- **转到行**：`⌃G`。
- **插入日期时间**：`F5`。
- **缩放**：`⌘+` / `⌘-` / `⌘0`（10%–500%）。
- **自动换行**：`⌥⌘W`（格式菜单可勾选）。
- **字体**：格式 → 字体…（系统字体面板）。
- **状态栏**：`⌘/` 显示或隐藏。
- **主题**：视图 → 主题（浅色 / 深色 / 跟随系统）。
- **标签切换**：`⇧⌘]` / `⇧⌘[`。
- **打印 / 页面设置**：`⌘P` / 文件 → 页面设置…。

## 编码与换行符

- 支持 UTF-8、UTF-16 LE/BE、UTF-32 LE/BE（带 / 不带 BOM）、GB18030（GBK / GB2312）、Big5、Windows-1252。
- 打开时自动检测；点击状态栏编码名称选择其他编码后**重新打开**生效，保存时保持当前编码与原换行符格式。
- 换行符 LF / CRLF / CR 自动识别，状态栏一键转换。

## 大文件

超过 10MB 的文件将以**只读模式**打开，编辑与保存被禁用，避免卡死。

## 打印

文件 → 打印…：页眉居中显示文件名，页脚显示「第 X 页 共 Y 页」；页面设置可调整纸张、方向与页边距。

## 常见问题

**打开某些中文文件显示乱码？**

点击状态栏编码，选择正确的编码（如 GB18030）后重新打开；保存时保持该编码。

**如何反馈问题？**

帮助 → 发送反馈…（邮件），请附上 macOS 版本与复现步骤。
